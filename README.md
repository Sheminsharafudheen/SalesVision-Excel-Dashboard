# 📊 SalesVision – Excel Sales Analytics Dashboard

An interactive sales dashboard built in **Microsoft Excel** using Pivot Tables, Pivot Charts and Slicers. It turns 1,800 raw sales orders into clear business insights on one screen.

---

## 🎯 Objective
Help a business answer simple questions quickly:
- How much are we selling, and how profitable is it?
- Which regions, categories and customer segments perform best?
- How are sales changing month by month?
- How many orders are delivered, cancelled or returned?

## 🛠 Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, Excel Tables, formulas)
- Custom dark theme with KPI cards

## 📁 Dataset
`SalesVision_Sales_Dataset.xlsx` – 1,800 orders (2024–2025) with order and ship dates, customer segment, region, state, city, category, sub-category, product, sales, quantity, discount, unit cost, profit, payment mode and order status.

## 📈 Key KPIs
| KPI | Value |
|---|---|
| Total Sales | ₹2.97 Cr |
| Total Orders | 1,800 |
| Total Profit | ₹0.68 Cr |
| Profit Margin | 22.9% |
| Units Sold | 3,062 |
| Avg Order Value | ₹16,501 |
| Avg Shipping Time | 3.3 days |

_Totals include Delivered, Cancelled and Returned orders._

## 💡 Key Insights
- 🏆 **South** is the top region, with about 28% of total sales.
- 💻 **Technology** is the top category, with about 78% of total sales.
- ⭐ **Gaming Laptop** is the best-selling product.
- 💳 **Credit Card** is the top payment mode by sales.
- ↩️ About **16.6%** of orders were returned, which is worth investigating.

## 🧩 Dashboard Features
- 7 KPI cards (sales, orders, profit, margin, units, average order value, shipping days)
- 6 Pivot Charts: monthly sales trend, sales by category, order status, sales by region, profit by region, sales by customer segment
- 3 Slicers (Region, Category, Customer Segment) that filter every chart at once

## 🚀 How to Use
1. Download `SalesVision_Dashboard.xlsx` and open it in desktop Excel.
2. Click the slicer buttons to filter the dashboard.
3. Hold **Ctrl** to select more than one option in a slicer.
